# Telegram IPA Distribution Bot

Бот принимает уже подписанный `.ipa` от одного администратора, сохраняет его на сервере и выдаёт прямую ссылку `https://ваш-домен/d/<случайный-токен>`.

При загрузке новой версии ссылка меняется, а предыдущий файл удаляется. Бот не подписывает IPA и не изменяет его.

## Важное ограничение Telegram

Через обычный облачный Telegram Bot API бот может скачивать файлы размером только до 20 МБ. Для больших файлов нужен **локальный Telegram Bot API server**. У локального сервера лимит загрузки файлов — до 2000 MB; поэтому фактический предел Telegram немного меньше математических 2 GiB.

Сам код проверяет размер до 2,000,000,000 байт. Для работы с крупными IPA настрой `TELEGRAM_API_SERVER` на адрес локального Bot API server. Одного увеличения лимита в Python недостаточно.

## Подготовка

1. Создай бота через `@BotFather` и скопируй токен.
2. Узнай свой числовой Telegram ID через `@userinfobot`.
3. Скопируй `.env.example` в `.env` и заполни:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `BASE_URL` — публичный HTTPS-домен, ведущий на этот сервер.
4. Установи Python 3.12+ и зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```

5. Запусти:

   ```bash
   python main.py
   ```

Веб-сервер слушает порт `8000`. Настрой reverse proxy (например, Nginx/Caddy) и HTTPS, чтобы домен `BASE_URL` направлял запросы на этот порт.

## Docker

```bash
docker compose up -d --build
```

Порт `8000` должен быть доступен через твой домен и HTTPS reverse proxy.

## Использование

- Отправь боту подписанный `.ipa` как **документ**, не как фото/медиа.
- Бот сохранит файл и пришлёт новую ссылку.
- `/link` — получить ссылку на текущую версию.
- `/start` — справка.

## Хранение

Файл и состояние лежат в `./data`. Для обновления бот заменяет текущую версию и удаляет старый IPA. Сделай резервную копию, если старые версии нужно хранить.

## Безопасность и эксплуатация

- Не публикуй токен бота и файл `.env`.
- Используй HTTPS.
- Убедись, что на диске есть место под IPA и временную копию во время загрузки.
- Ссылка является секретным токеном: любой, у кого она есть, сможет скачать текущий IPA.
- Это минимальный рабочий каркас; для публичного сервиса стоит добавить авторизацию/лимиты скачивания, журналирование и резервное копирование.
